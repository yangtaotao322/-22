# 动作清单

本文档提供命令类动作编号的静态参考，实际可用动作以设备查询结果为准，可用于：

- `play_action.action`

说明：

- 对外调用时应传 `get_motion_info_list` 返回的 `motion_id`。
- `get_motion_info_list` 仅返回 `motion_type = 2` 的命令类动作。
- 对话类动作和特殊动作由机器端交互流程管理，不属于 `play_action` 的对外调用范围。
- 设备运行版本可能更新动作清单，调用前应通过 `get_motion_info_list` 查询实际结果。
